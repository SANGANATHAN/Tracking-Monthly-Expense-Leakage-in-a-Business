# 📊 Tracking Monthly Expense Leakage in a Business

### An Excel-Based Business Expense Analysis and Dashboard Project

A data analytics project focused on identifying business overspending by comparing budgeted expenses with actual spending across departments, expense categories, months, and years using Microsoft Excel.

---

## 📌 Project Overview

Businesses allocate monthly budgets to departments such as Marketing, Operations, Finance, Logistics, Administration, and Human Resources. However, actual expenses may exceed the planned budget, leading to financial inefficiencies and reduced profitability.

**Tracking Monthly Expense Leakage in a Business** aims to analyze these spending patterns, identify budget variances, and highlight areas that require further investigation.

Using Microsoft Excel, this project transforms expense data into an interactive dashboard that helps users compare budgets with actual expenses and understand spending trends.

## 🎯 Project Objectives

- Compare budgeted expenses with actual spending.
- Identify departments with significant budget variances.
- Analyze expenses across different categories.
- Monitor monthly and yearly spending patterns.
- Calculate budget variance and variance percentage.
- Identify potential areas of unnecessary spending.
- Support better budgeting and cost-control decisions.

## 📐 Key Calculations

### 1. Budget Variance

Variance measures the difference between actual spending and the budgeted amount.

```text
Variance = Actual Spend - Budgeted Amount
```

- Positive variance: Actual spending exceeds the budget.
- Negative variance: Actual spending is below the budget.
- Zero variance: Actual spending equals the budget.

### 2. Variance Percentage

```text
Variance Percentage =
((Actual Spend - Budgeted Amount) / Budgeted Amount) * 100
```

This calculation expresses the budget variance as a percentage of the budgeted amount. It requires a non-zero budget.

## 🔍 Project Methodology

The project follows these steps:

1. **Data Collection:** Generated a sample business expense dataset using ChatGPT.
2. **Data Understanding:** Examined the dataset structure, columns, departments, categories, and spending periods.
3. **Data Cleaning:** The dataset was reported as clean and structured when collected; no additional cleaning was performed.
4. **Data Transformation:** No additional transformation or new column creation was performed, according to the project methodology.
5. **Data Analysis:** Compared budgeted and actual expenses and analyzed variances using Excel.
6. **Data Visualization:** Created charts and PivotTables to summarize spending patterns.
7. **Dashboard Development:** Combined the analysis into an interactive dashboard.
8. **Conclusion:** Identified areas where management could investigate potential overspending and improve cost control.
